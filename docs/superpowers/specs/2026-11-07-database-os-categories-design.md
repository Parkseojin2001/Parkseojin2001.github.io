# Database / Operating System 카테고리 정리

사용자 피드백에 따라 기본 내용 위주의 Database를 두 개의 하위 카테고리로 단순화하고, Operating System은 전공수업 기록으로 정리한다. 두 주제는 각각 독립된 최상위 카테고리다.

| 상위 | 하위 | 기존 글 번호 | 폴더 | 글 수 |
| --- | --- | --- | --- | --- |
| Database | SQL | 03–13 | database/sql | 11 |
| Database | Basics | 01–02, 14–28 | database/basics | 17 |
| Operating System | Course Notes | 01 | operating-system/course-notes | 1 |

SQL 문법, 저장 함수, 프로시저, 트리거는 SQL에 포함한다. DB 개념, 트랜잭션, 설계, 인덱스, 아키텍처, NoSQL 소개는 기초 이론으로 묶는다. OS는 현재 한 편이므로 전공수업 아래에서 글을 축적한다.

이전의 7개 Database 하위 분류는 기초 글 모음에 비해 지나치게 세분화되어 사용하지 않는다. 글과 이미지 폴더를 맞추고 기존 본문과 permalink를 보존한다. SQL과 저장 프로그램이 합쳐져 DB 공용 이미지도 sql에 둔다. 삭제되는 기존 최상위 카테고리 주소는 /categories/cs/ 하나다.
